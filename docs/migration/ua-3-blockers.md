# UA-3 Blocker 记录

## F1 UA-3-1-016 RT 恢复延迟波动（flaky，非产品缺陷）

| 字段 | 值 |
|------|-----|
| 影响 Case | UA-3-1-016（数据源重新启用） |
| 现象 | 真实环境长跑（全量 UA-3 串行回归）时偶发失败：重新启用数据源后 RT 在 120s 窗口内未恢复有效值；单独运行该用例时稳定 PASS |
| 是否产品缺陷 | 否。与 UA-1-2-03/05 同一根因：真实环境 RT 恢复延迟随重复启停累积增长（实测 2s~120s+），120s 轮询超时在长跑中不够 |
| 是否稳定复现 | 否（flaky） |

### 分析

- 用例流程：`change_ds_state(ds_id, False)` → `_rt_quality_invalid(timeout=120)` → `change_ds_state(ds_id, True)` → `wait_rt_matches_source(timeout=120)`。
- 长跑中数据源被反复启停（UA-3-1-013/014/015 依赖同一类操作），重新启用后的采集恢复延迟随累积启停次数增长，单个 120s 窗口偶发不足。
- 单独运行时前面没有累积启停，恢复延迟短，用例稳定通过。

### 处理

- 不视为 blocker，不计 FAIL；回归结果以"单跑 PASS + 长跑偶发超时"记录。
- 如后续长跑再次出现 UA-3-1-016 超时，视为 flaky 重跑确认，不作为产品 FAIL 上报。

## 影响总览

| 维度 | 值 |
|------|-----|
| 阻塞迁移 | 无 |
| blocker 引起 FAIL | 0 |
| 说明 | UA-3-1-016 为已知 flaky（RT 恢复延迟），非产品能力限制 |
